Video grid

Drop an MP4 or WebM. It plays, muted and hidden, entirely in this tab (an object URL — nothing is ever uploaded) and every sampled frame is downsampled the same way the picture grid downsamples a still image, then pushed into the grid through its ordinary row-update path. A 10–20s clip, 720p or smaller, samples fastest.

Grid — one column per pixel, one push per sampled frame

Frames are sampled via requestVideoFrameCallback (falling back to requestAnimationFrame where unsupported) and dropped — never queued — whenever the grid hasn't finished painting the previous one, or the level's frame-rate cap hasn't elapsed yet: this page reports the fps the grid actually achieves, not the cap. See README for the numbers this was tuned against.
